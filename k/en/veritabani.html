Databases

Learning to write queries is easy; getting the schema right is hard — later performance problems usually trace back to modelling decisions made on day one. Spend separate time on indexing: the cause of slowness is almost never the query itself.

12 links

Couchbase Learn

learn.couchbase.com

Queries a document store with a SQL-like language (N1QL), which is a gentler break for teams arriving from the relational world than MongoDB’s query syntax.

Free, Database, Curriculum

Firebase

firebase.google.com

Realtime database, auth, storage and hosting in one package. It accelerates a prototype sharply, while query flexibility and vendor lock-in become the later problem.

Paid, Freemium, Backend, API

İlişkisel Veritabanı Tasarımı

youtube.com

A full course on normal forms and schema design. It teaches getting the tables right rather than writing queries — which is where every later problem originates.

Video, Free, Database

MongoDB University

learn.mongodb.com

MongoDB’s official free courses. The data modelling unit is the important one — designing a document store with relational habits is the most common source of performance trouble.

Free, Database, Curriculum

MySQL Tutorial

mysqltutorial.org

Works MySQL end to end over a sample database, treating join types, subqueries and stored procedures separately. Far more readable as an introduction than the official manual.

Free, Database

Oracle SQL Developer

oracle.com

A free desktop client for Oracle databases combining querying, schema browsing and PL/SQL debugging — the de facto tool if you work with Oracle.

Free, Database

PostgreSQL Tutorial

neon.com

A PostgreSQL tutorial showing each topic with a runnable query, going deep on window functions and CTEs where most SQL courses stop.

Free, Database

SQL Nasıl Öğrenilir

reddit.com

A thread where experienced users argue over how to learn SQL. Because nobody there is selling a course, the filtering is already done.

Free, Awesome List, Database

SQL Sıfırdan İleri Seviye

youtube.com

SQL from basics to advanced in four hours for anyone who wants the whole picture in one sitting. It reaches window functions rather than stopping at basic SELECT.

Video, Free, Database

SQLite

sqlite.org

A serverless embedded database living in a single file — the most widely deployed database engine in the world, with a copy inside nearly every app on your phone. Its test coverage is legendary.

Open Source, Database

Turso

turso.tech

A database platform built on libSQL, a SQLite fork, that replicates the database to edge nodes near the user. Unlike centralised services such as PlanetScale, read latency becomes local file access rather than a network round trip.

Database, Open Source

Veritabanları Derinlemesine

youtube.com

A course on internals — index structures, transaction isolation levels, locking. Not a product tutorial; it holds regardless of which database you use.

Video, Free, System Design
