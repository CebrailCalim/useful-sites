DevOps & Infrastructure

Most of these tools mean little alone — they are parts of a stack, usually assembled in this order: version control, containers, deployment, then monitoring. On hosting, the gap between the big clouds and Hetzner-class providers is a multiple in price.

38 links

AlexHost

alexhost.com

Moldova-based hosting chosen for a different jurisdiction and looser content policy — which also raises the question of who your neighbours are.

Paid, Server, Privacy

Amazon Web Services

aws.amazon.com

The cloud with the widest service range. The breadth is an advantage, while cost tracking is its own discipline — egress charges in particular catch people out.

Paid, Server

Apache Airflow

airflow.apache.org

You define DAGs in Python and schedule them. The de facto standard for batch data pipelines, and clumsy for event-driven, low-latency work.

Open Source, Python, Automation, Data Science

Apache HTTP Server

httpd.apache.org

A module architecture plus per-directory configuration through .htaccess. Still dominant in shared hosting, and hungrier for memory than nginx under high concurrency.

Open Source, Server, Docs

Apache Kafka

kafka.apache.org

Retains messages after consumption, with consumers carrying their own offsets so they can replay history. That durability is the real split from classic queues.

Open Source, Automation

AvenaCloud

avenacloud.com

A VPS and dedicated server provider positioned on budget for small-scale projects.

Paid, Server

Celery

docs.celeryq.dev

The standard for background tasks in Python, using Redis or RabbitMQ as a broker, with scheduled tasks (beat) and retry logic included.

Open Source, Python, Automation

Coder

coder.com

Runs development environments as containers on your own infrastructure, reached from a VS Code or JetBrains client. Against GitHub Codespaces it is not tied to a cloud provider — both the compute and the code stay with you.

Open Source, Self-Hosted, Server, DevOps

Cronmaster

github.com

A self-hosted web interface for cron jobs that renders expressions in readable form and keeps a run log. Against `crontab -e` it shows the next run time and the last output, which makes silently failing jobs visible.

Open Source, Self-Hosted, DevOps

Crontab Generator

crontab-generator.org

Builds a cron expression from a form and states in words when it will fire. Against crontab.guru it runs the other way: instead of decoding an expression, it produces one from the schedule you describe.

In Browser, Free, DevOps

Dokploy

github.com

Brings a Vercel-like deploy experience to your own VPS — git-push deploys, database provisioning, automatic TLS. It fills the hole left when Heroku’s free tier closed.

Open Source, GitHub, Self-Hosted, Docker

FromLatest

fromlatest.io

Analyses a Dockerfile, explains what happens layer by layer and suggests improvements. Against hadolint it is visual and states why each rule exists, which makes it usable for learning to write Dockerfiles rather than only linting them.

Docker, In Browser, DevOps

Gource

gource.io

Renders repository history as a growing animated tree where you see who touched what. Not an analysis tool — a way to narrate a project’s history.

Open Source, Git, Interactive

Grafana

grafana.com

Unifies Prometheus, Loki, PostgreSQL and dozens of sources on one dashboard. Being data-source agnostic is how it became the shared face of monitoring stacks.

Open Source, Observability

Güzel Hosting

guzel.net.tr

Turkey-based hosting and domains with .tr registration, local payment and Turkish support — practical when the server has to sit in Turkey.

Paid, Turkish, Server

Hetzner

hetzner.com

Dedicated servers and VPS in Germany and Finland at a fraction of the big clouds’ price for the same cores and RAM. No managed services — operations are entirely yours.

Paid, Server

K8s YAML Generator

k8syaml.com

Generates Kubernetes manifests from a form, explaining each field beside it. Against copying from the docs you leave with a valid manifest and pick up what the fields mean on the way.

DevOps, In Browser, Free

Kestra

kestra.io

Flows are declared in YAML, and being language-agnostic it works for teams that are not on Python. It sits well in version control.

Open Source, Automation, DevOps

LiteSpeed

litespeedtech.com

A commercial server that reads Apache configuration as-is while using an event-driven core and fewer resources. Common in WordPress hosting alongside its cache plugin.

Paid, Server

LiteSpeed Dokümantasyonu

docs.litespeedtech.com

The configuration reference, including how LSCache rules are written — cache settings account for most of the performance you get.

Docs, Server, Database

Make

make.com

Scenarios carry branching, loops and error handling, which makes complex flows easier than Zapier’s linear steps. The learning curve is correspondingly steeper.

Paid, Freemium, Automation

n8n

n8n.io

A visual node editor with unmetered executions when self-hosted. You can drop JavaScript into a node, so you do not hit the usual no-code wall.

Open Source, Self-Hosted, Automation, Docker

n8n Dokümantasyonu

docs.n8n.io

Node reference, self-hosting and credential management. The queue-mode scaling section matters for anyone running it in production.

Docs, Automation

Neko

github.com

Runs a browser in a container and shares it over WebRTC, with several people able to control one session. Used for watch-together and for isolated browsing.

Open Source, GitHub, Docker, Networking

nginx

nginx.org

Its event-driven architecture carries tens of thousands of concurrent connections on little memory. It is used as a reverse proxy and load balancer more often than as a web server.

Open Source, Server

Njalla

njal.la

Registers the domain in its own name on your behalf, so you do not appear in WHOIS. Unlike a privacy proxy the legal ownership sits with them, which makes it a question of trust.

Paid, Privacy

Pipedream

pipedream.com

Any step can be Node.js or Python and can pull an npm or PyPI package. The option that closes the gap between visual automation and real code.

Paid, Freemium, Automation, System Design

Power Automate

microsoft.com

SharePoint, Teams and Dataverse connectors are native. If the organisation is already on Microsoft 365 the licence is usually paid for — which is the real reason it gets chosen.

Paid, Automation

Prefect

prefect.io

A flow is an ordinary Python function you decorate into orchestration. Moving local code to production is shorter than learning Airflow’s separate DSL.

Open Source, Python, Automation

Pro Git (Türkçe)

git-scm.com

The Turkish translation of Git’s official book. The internals chapter — object model, refs — is what frees you from memorising commands and actually makes Git make sense.

Free, Turkish, Book, Git

RabbitMQ Öğreticileri

rabbitmq.com

The official six-step series on queue patterns — work queues, pub/sub, routing, RPC. Kafka is for event streaming; this is for task distribution.

Open Source, Automation

Redis Dokümantasyonu

redis.io

The reference for its data structures — lists, sets, sorted sets, streams. Treating Redis as a plain key-value store means leaving most of the tool unused.

Docs, Database

Sentry

sentry.io

Collects errors with stack traces, source maps and user context, grouping duplicates. Against reading log files, it tells you how many users a given error actually hit.

Freemium, Open Source, Observability

ShellCheck

shellcheck.net

A static analyser for shell scripts that finds unquoted variables, wrong test syntax and portability traps. Against `bash -n` it checks meaning rather than syntax, so it catches the script that runs and misbehaves.

Open Source, CLI, Free

Temporal

temporal.io

Records workflow state as an event history, so a crashed process resumes at the same point. Built for multi-day operations that cannot simply be restarted.

Open Source, Automation

Vercel

vercel.com

Frontend-focused deployment whose per-PR preview environments became an industry standard. It is the company behind Next.js, so integration with that framework is tightest here.

Paid, Freemium, Server, Embedded

YAMLlint

yamllint.com

A YAML validator that surfaces indentation and quoting errors and prints the parsed document back. Against a JSON validator it catches YAML’s actual trap: indentation that silently produces the wrong structure.

In Browser, Free, DevOps

Zapier

zapier.com

The widest integration catalogue — the niche SaaS you want is probably already there. Pricing is per task, so it gets expensive quickly as volume grows.

Paid, Freemium, Automation
